# Week 5 - Advanced Object-Oriented Programming

## Overview

This week explores object interaction, static members, friend functions, and complex number operations.

## Learning Objectives

* Pass objects as function parameters
* Use static data members
* Understand friend functions
* Perform operations on custom objects

## Experiments

### Experiment 1: Payroll System

Calculate weekly employee pay using Payroll objects.

### Experiment 2: Travel Class

Pass objects as function parameters and combine travel information.

### Experiment 3: Static Data Members

Count the number of objects created using a static variable.

### Experiment 4: Complex Number Operations

Perform addition, subtraction, and multiplication.

### Experiment 5: Friend Functions

Access private data through friend functions.

## Concepts Covered

* Object Passing
* Static Members
* Friend Functions
* Complex Numbers
* Class Relationships

## Language Used

C++

## Outcome

Students learned advanced class features and object communication techniques.
